# Contribuir

1. Cria uma branch pequena e descreve o problema que resolve.
2. Não incluas passwords, tokens, extratos, carteira, notas pessoais ou
   outputs gerados.
3. Executa `python -m unittest discover -s tests -q` antes de abrir um pull
   request.
4. Explica alterações de segurança, privacidade, providers e licença.

Issues públicos não são o canal para reportar vulnerabilidades. Consulta
`SECURITY.md`.
